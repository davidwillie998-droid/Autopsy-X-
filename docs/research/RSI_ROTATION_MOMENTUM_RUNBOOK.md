# RSI Rotation Momentum — Research Runbook

**Mode:** Offline research only  
**Execution authority:** None  
**Current verdict:** NOT APPROVED pending real-data, cost, and walk-forward validation

## 1. Install dependencies

From the repository root:

```bash
python -m pip install numpy pandas
```

## 2. Prepare the M15 input

Create a CSV with one row per completed M15 candle and these required columns:

```text
timestamp,symbol,market_family,open,high,low,close
```

Use UTC timestamps. Do not include a still-forming candle. Do not forward-fill missing prices. Preserve the source archive and document broker/provider, symbol specification, timezone conversion, and extraction time.

Optional context columns:

```text
h1_alignment,h4_alignment
```

Both columns must be supplied together. Values are -1, 0, or +1. They must represent the last fully completed H1/H4 candle available at the M15 timestamp. The harness cannot independently verify that alignment; the data-preparation process must prove it.

## 3. Prepare family-specific benchmarks

Create a JSON object mapping every market family in the CSV to a benchmark symbol that is also present in the CSV. Example only:

```json
{
  "FX": "DXY",
  "METAL": "XAUUSD",
  "EQUITY": "SPY"
}
```

Do not use this example blindly. Choose and document a defensible benchmark for each universe. Do not mix synthetic indices with FX, metals, equities, or crypto without a separate calibration and benchmark decision.

## 4. Run the baseline

```bash
python scripts/research/rsi_rotation_baseline.py \
  --input data/research/m15_universe.csv \
  --benchmark-map data/research/benchmark_map.json \
  --output-dir artifacts/rsi_rotation
```

Outputs:

- `rsi_rotation_observations.csv`: point-in-time features, scores, ranks, states, and forward-return labels
- `summary.json`: coverage, status counts, rank spreads, input hash, and explicit NOT_APPROVED verdict

A cross-sectional composite score is emitted only when both H1/H4 context is supplied and at least three instruments are eligible in that market-family/timestamp cross-section. Otherwise the row remains unranked. This is deliberate fail-closed behaviour.

## 5. Unit tests

```bash
python -m pip install pytest numpy pandas
python -m pytest tests/research/test_rsi_rotation_baseline.py -q
```

The tests cover Wilder RSI initialization and edge cases, required higher-timeframe context, minimum universe size, duplicate rows, and future-injection invariance.

## 6. Research limitations — do not misread the report

- Forward returns are labels, not strategy P&L.
- Spread, commission, swap/funding, slippage, latency, market impact, and turnover costs are not applied by this baseline.
- No walk-forward or out-of-sample verdict is generated by this script.
- The RSI and composite weights are pre-registered starting hypotheses, not optimized parameters.
- The H1/H4 alignment columns are trusted inputs; their no-lookahead construction must be independently tested.
- A successful unit-test run proves software invariants only. It does not establish predictive value or profitability.
- No output from this module may place orders, alter EA sizing, authorize flips, or enable pyramiding.
